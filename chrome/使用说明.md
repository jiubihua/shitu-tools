# 拾图 v1.7.0 · 直接选择系统文件夹保存

## v1.7.0 视频悬停预览与系统主题
- 视频改为弹窗内直接预览，与图片同样使用三列布局、110px 高的预览区域。
- 画面完整保持原始比例，横屏和竖屏均不裁切、不拉伸，空余区域留边。
- 鼠标移入视频画面时静音循环播放，移出暂停；再次移入继续。切走窗口、页面隐藏或重新提取时暂停或释放旧预览。
- 支持键盘聚焦预览，回车或空格切换播放。预览主地址失败时尝试备用地址；所有地址失败时显示提示，仍可尝试保存。
- 界面自动跟随系统浅色、深色外观；无需刷新即可切换。这里的“亮度”指系统外观模式，不是显示器背光数值。
- 不增加扩展权限；保存、笔记文件夹及 TXT 清单选项保持独立。
- 本地验证覆盖预览交互、画面尺寸、比例样式和主题切换。小红书 CDN 的实际视频预览仍可能受链接有效期、编码及防盗链限制。

## v1.6.1 两个独立选项
- 「创建笔记文件夹」：决定是否在所选目录下创建笔记标题文件夹。
- 「生成 TXT 清单」：决定是否在素材同目录生成「来源与图片清单.txt」。
- 两项互不依赖，分别记住选择。升级时保留旧版的勾选状态，之后可单独调整。
- 仅勾文件夹：创建笔记文件夹并保存素材，不生成清单。
- 仅勾清单：素材及清单直接保存在所选目录。
- 都勾选：笔记文件夹内保存素材及清单；都不勾选：只在所选目录保存素材。
- 顶部保留并排的「保存」「重新提取」，保存当前勾选的素材。

## 现有保存规则
- 保留系统文件夹选择方式，勾选选项时，在所选目录下创建笔记标题文件夹。
- JPG 图片、MP4 视频直接放在笔记文件夹里，不按类型分子文件夹。
- 自动创建同目录的「来源与图片清单.txt」，采用你提供的清单结构：标题、来源、保存日期、图片数量、转换说明，以及文件名、尺寸、实际字节数。
- 视频增加单独的数量统计，并列出文件名、格式和实际字节数。
- 清单边保存边更新，结束时写入本次成功/失败数量和错误说明。
- 重复保存时，统计该目录已有 JPG 和 MP4，包含此前已保存的文件；同名素材自动加序号。
- TXT 使用 UTF-8（带 BOM），日期使用北京时间。

保存结构：所选目录 / 笔记标题 / 01.jpg、02.jpg、01.mp4、来源与图片清单.txt。

注意：示例里的质量100、4:4:4采样、原始文件备份不是当前工具的处理设置。清单如实记录 JPG 质量参数95、保持原像素尺寸、色度采样由浏览器决定、未另存原始文件，不会声称已完成未实现的处理。

## 安装 / 从旧版升级
1. 解压安装包，把 `xhs-image-tool` 文件夹放在固定位置。
2. 打开 `chrome://extensions`，开启「开发者模式」。
3. 首次安装：点击「加载已解压的扩展程序」，选择包含 manifest.json 的文件夹。
4. 升级：用新版文件替换原来加载的扩展目录内容，点击扩展的「重新加载」。也可以移除旧版，再加载新版目录。
5. 确认扩展版本为 **1.7.0**，弹窗右上角显示 **v1.7.0**，刷新小红书页面。
6. 新版重新使用后台处理权限，以便选择目录后关闭弹窗也能继续保存。

## 使用
1. 打开小红书网页版的笔记详情，等图片加载，视频可先播放。
2. 点工具栏「拾图」，自动读取并预览图片、视频。
3. 勾选素材后点击顶部「保存」。
4. 在系统文件夹选择框里选择目标目录，并允许写入。
5. 素材在后台自动保存，可以关闭扩展弹窗、切回网页。请保持 Chrome 运行。
6. 重新打开扩展查看最近一次保存的成功数量和错误原因。文件直接在目标目录中，不在 Chrome 下载记录里。

每批都会让你选目录，方便明确这批素材的保存位置。取消选择不会写入文件。遇到重名会增加序号，避免覆盖已有文件。

macOS 上显示的是系统原生文件夹选择框，外观类似访达；扩展不会启动一个独立访达窗口。

## 支持范围
- 桌面 Chrome 116 或更新版本，需要支持 File System Access API。浏览器策略或目录权限可能禁止选择或写入。
- 图片实际解码并重新编码为 JPG，质量参数 95%，保持像素尺寸，透明区域填白；动图只存静态画面。
- 视频支持能读取到的直接 MP4 地址，保持原编码。仅有 blob 地址且笔记数据中也没有可用直链、M3U8 分段流、DRM 和直播暂不支持。
- 图片上限 50 MiB / 8000 万像素，单个视频上限 500 MiB，读取超时 3 分钟。单个素材失败不会停止其余素材保存。
- 不承诺原图、去水印或最高分辨率；网页结构变化、链接过期或防盗链可能影响提取。
- 退出 Chrome 或重新加载扩展会中断进行中的任务。

## 隐私
所有转换和写入都在本机完成，不上传到第三方服务器。只向你在系统选择框中授权的目录写入。为跨扩展上下文传递目录授权，目录句柄会临时存入扩展的 IndexedDB；后台接收后删除该记录。任务进度保存在当前浏览器会话中。
